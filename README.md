# 🍱 HOMEPLATES

HOMEPLATES is a homemade food/tiffin service website.

It connects **customers** with **local food suppliers**.

## ⭐ Features

### 👤 Customer
- Create account
- Login
- See available meals
- Add food to cart
- Enter delivery address
- Place order
- Check order status

### 👨‍🍳 Supplier
- Create account
- Login
- Add meals
- Upload food image
- Add price and quantity
- See customer orders
- Update order status

## 🔄 How It Works

Customer:

Login → Choose Food → Add to Cart → Add Address → Place Order

Supplier:

Login → Add Food → Receive Order → Update Order

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- LocalStorage

## ▶️ How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using HOMEPLATES.

## 🎯 Project Goal

The goal of HOMEPLATES is to help people find fresh homemade food from local suppliers.
